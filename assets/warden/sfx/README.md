# Warden combat SFX

Drop Mixkit (or other) WAVs here. `CombatSfx.js` will pick them up automatically.

Suggested filenames (any of these work):

| Logical | Example files |
|---------|----------------|
| whoosh | `mixkit-metal-hit-woosh-1485.wav`, `whoosh.wav` |
| strike | `mixkit-metallic-sword-strike-2160.wav`, `strike.wav` |
| impact | `mixkit-samurai-sword-impact-2789.wav`, `impact.wav` |
| heavy | `mixkit-heavy-sword-smashes-metal-2795.wav`, `heavy.wav` |
| block | `block.wav` |
| deflect | `deflect.wav` |

If a file is missing, CombatSfx synthesises a short fallback so combat is never silent.
